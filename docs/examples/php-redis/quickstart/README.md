# PHP + Redis quickstart

This consumer uses the real Dilock PHP Redis adapter. It runs two resource scopes sequentially on one provider: a default 5-second wait / 30-second lease, then an explicit 3-second wait / 20-second lease. The handles share the provider's command and cleanup clients. Redis executes the package's owner-checked Lua scripts; no Redis-side service installation is needed. The PHP SDK is experimental and Redis does not supply strong fencing in this profile.

Prerequisites: PHP 8.1+, Composer autoload files, the Redis PHP extension, a reachable Redis server, and pre-provisioned namespace metadata matching `DILOCK_EPOCH` (defaults to `local-redis-epoch`) and `DILOCK_NAMESPACE` (defaults to `default`). See [`spec/NAMESPACE-METADATA.md`](../../../../spec/NAMESPACE-METADATA.md). The SDK does not provision metadata.

From the repository root:

```sh
composer install --working-dir=sdk/php
php docs/examples/php-redis/quickstart/main.php
```

The code requires the repository's `sdk/php/vendor/autoload.php`, generated by Composer. Point `DILOCK_REDIS_URL` and the epoch at your prepared environment before running.
