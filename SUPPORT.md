# Support

Use the repository issue tracker for reproducible bugs and design proposals once it is available. Include SDK/backend/server/client versions, expected vs actual behavior, a minimal reproducer, sanitized logs and whether a fault/restore/failover was involved. Use the security route for vulnerabilities.

There is no commercial support or availability SLA. SDKs and backend adapters are experimental; support varies by language/backend, and no production support or failover guarantee is implied.
